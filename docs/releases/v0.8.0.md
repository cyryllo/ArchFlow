AI assistants can now draw ArchFlow diagrams for you. New since [v0.7.0](https://github.com/cyryllo/ArchFlow/releases/tag/v0.7.0).

### 🤖 MCP server: `archflow-mcp`

ArchFlow now has an **MCP server**. Claude Desktop, Claude Code and other apps that support the Model Context Protocol can build and change diagrams from a plain description, e.g. *"draw our shop: browser, load balancer, two app servers, PostgreSQL with a replica"*.

- **Whole diagrams in one go:** nodes with any of the 177 icons, coloured zones with titles, connectors with labels and line styles, and texts.
- **Automatic layout on the isometric grid.** Zones go left to right like layers, and a zone can be a single row for a process. You can also ask for exact positions.
- **Changes to existing diagrams:** add, change or remove nodes, connectors and zones, rename diagrams, export to JSON. The assistant can also read your diagrams and answer questions about them.
- **Saved where ArchFlow looks:** your Docker server (`ARCHFLOW_URL`) or the desktop app's `Documents/ArchFlow` folder. The diagram then appears in *My diagrams*.
- **Checked before saving** with ArchFlow's own rules. Mistakes, such as an unknown icon, go back to the assistant with suggestions.
- Icons can be searched in all 10 interface languages.

Setup takes one command for Claude Code, or a few lines of config for Claude Desktop. Everything is in **[AI assistants (MCP)](https://github.com/cyryllo/ArchFlow/blob/master/docs/mcp.md)** ([Polski](https://github.com/cyryllo/ArchFlow/blob/master/docs/mcp.pl.md)).

~~~bash
claude mcp add archflow --scope user -e ARCHFLOW_URL=http://localhost:9500 -- npx -y archflow-mcp
~~~
