ArchFlow now speaks 10 languages. New since [v0.6.3](https://github.com/cyryllo/ArchFlow/releases/tag/v0.6.3).

### 🌍 New interface languages

Besides English and Polish, the whole interface is now available in:

**Deutsch · Français · Español · Italiano · Português (Brasil) · Čeština · Nederlands · Українська**

- Everything is translated: toolbar, menus, panels, settings, help, dialogs, *My diagrams*, and the desktop app's "unsaved changes" window.
- **Icon names and categories too**: all 177 icons in the picker have names in each language, and the search works with them.
- **☰ → Language** now opens a list of all languages instead of switching between two. Your choice is remembered.

### ✨ Smaller improvements

- Long icon names in the picker (e.g. German compound words) wrap onto a second line instead of being cut off.
- The page tells the browser which language it's in, which helps screen readers.

### 📖 Documentation

The README, the [user manual](https://github.com/cyryllo/ArchFlow/blob/master/docs/manual.md) (chapter *Language*, with a new screenshot) and the website list the new languages.
