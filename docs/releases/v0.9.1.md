Diagrams can now be private and shared with chosen people or through a link. New since [v0.9.0](https://github.com/cyryllo/ArchFlow/releases/tag/v0.9.0).

### 🔗 Sharing (ArchFlow in Docker with logins)

In *My diagrams*, the author of a diagram or an administrator clicks **Share**:

- **Team or private.** *Team* (the default, as before) is visible to everyone logged in. *Private* is visible only to the author, administrators and the people it's shared with.
- **Sharing with people.** Each person gets *Can view* or *Can edit*. A viewer can only view, whatever is chosen. Only the author or an administrator changes the sharing; an editor with edit access can change the diagram but not share it further.
- **Read-only links.** Anyone with the link sees the diagram without an account, and nothing can be changed through it. Links can expire after 7, 30 or 90 days and can be revoked at any time. With logins, they replace the old `/display/<name>` addresses, which now need a login.
- **My diagrams** marks private diagrams, diagrams shared with you, and diagrams you can only view.
- A diagram shared with you to view opens read-only, without *Save*.
- The sharing is kept inside the diagram file, so renaming a diagram keeps it. A normal save can't change it, and only the author and administrators see who it's shared with.
- AI assistants (MCP) follow the same rules: a token sees and changes only what its owner may.

All of it is translated into the 10 interface languages.

### 🐛 Fixes

- The Docker build no longer reads the local `diagrams` folder and `.env` file (a new `.dockerignore`). This only mattered when building the image yourself.
- In *My diagrams*, the colours of the *Load* and *Delete* buttons no longer depend on which buttons a diagram has.

### 🐳 Docker

~~~bash
docker compose pull
docker compose up -d
~~~

Your diagrams in `./diagrams` are kept. Diagrams from earlier versions are team diagrams; without an author, only administrators can share them.
