The MCP server is now built into the Docker image. New since [v0.8.0](https://github.com/cyryllo/ArchFlow/releases/tag/v0.8.0).

### 🤖 MCP in Docker

AI assistants can now connect **straight to your ArchFlow server** over HTTP, with nothing to install on your computer.

- **Off by default.** Set `MCP_TOKEN` for the container to turn it on. Assistants then connect to `http://your-server:9500/mcp` and send the token.
- **Same tools as before:** build and change diagrams, read them, find icons. Diagrams are saved to the server and appear in *My diagrams* for everyone.
- **Clear answers when something is missing.** Without the right token the server answers *Missing or wrong token*. A container without `MCP_TOKEN` answers *The ArchFlow MCP server is off*.
- **Links** in the assistant's answers use the address it connected to, also behind a reverse proxy.

Turning it on:

~~~bash
echo "MCP_TOKEN=$(openssl rand -hex 32)" >> .env
docker compose up -d
~~~

Connecting Claude Code:

~~~bash
claude mcp add --transport http archflow --scope user http://your-server:9500/mcp \
  --header "Authorization: Bearer <your token>"
~~~

The full guide, including `.mcp.json`, security and troubleshooting, is in **[AI assistants (MCP)](https://github.com/cyryllo/ArchFlow/blob/master/docs/mcp.md#mcp-in-docker-over-http)** ([Polski](https://github.com/cyryllo/ArchFlow/blob/master/docs/mcp.pl.md#mcp-w-dockerze-przez-http)).

The npm package can run the same HTTP server on its own: `MCP_TOKEN=… npx -y archflow-mcp@latest --http`.

### 🧠 Better with smaller and local models

Tested with local models through Ollama (`qwen3:30b-a3b`, `gemma4:26b`):

- **Made-up icon ids no longer block the diagram.** An unknown id such as `raspberry-pi` or `nextcloud` is replaced with the closest icon, the diagram is saved, and the assistant is told which icon was used, so it can change it.
- **Smarter icon search.** A search with several words ("load balancer", "Home Assistant") finds icons that match any of them, best match first. When nothing fits, the answer says the icons are generic rather than product logos, and suggests the closest ones.
- Diagrams saved to a folder (the desktop app) now carry their name, so the app's title bar shows it instead of "Loaded Diagram".

### 🐳 Docker

~~~bash
docker compose pull
docker compose up -d
~~~

Your diagrams in `./diagrams` are kept. To use MCP, also add `MCP_TOKEN` to `.env` (see above). If your `compose.yml` is older than this release, download the new one, which passes `MCP_TOKEN` to the container, or add `- MCP_TOKEN=${MCP_TOKEN:-}` under `environment`.
