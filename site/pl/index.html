Izometryczne diagramy systemów i procesów, bez kombinowania

ArchFlow to edytor czytelnych, ładnych diagramów izometrycznych: architektury systemów, sieci, infrastruktury chmurowej i procesów biznesowych. Używaj go w przeglądarce, zainstaluj na Linuksie lub Windows albo uruchom u siebie jednym poleceniem Dockera.

▶ Wypróbuj demo ⬇ Pobierz 🚀 Szybki start 🐳 Uruchom w Dockerze

Co możesz zrobić

Wszystko, czego potrzebujesz, żeby rozrysować architekturę albo proces, wytłumaczyć je innym i utrzymać diagram w aktualności.

🧊

Płótno izometryczne

Układaj elementy na siatce izometrycznej, grupuj je w kolorowe strefy, łącz i dodawaj teksty. Przybliżaj, przesuwaj i dopasowuj cały diagram do ekranu.

🎨

177 ikon w 9 kategoriach

Jeden spójny zestaw ikon, z kolorem dla każdej kategorii: serwery i komputery, sieć, komunikacja, dane, bezpieczeństwo, ludzie, przepływ i procesy, biznes i logistyka, kształty.

🔀

Nie tylko infrastruktura

Rysuj też procesy biznesowe i zamówień: zdarzenia początkowe i końcowe, decyzje, bramki, dokumenty, akceptacje, czasomierze i kamienie milowe.

🖱️

Wszystko pod prawym przyciskiem

Na pustym polu dodasz węzeł, strefę i tekst; na elemencie połączysz, skopiujesz, zduplikujesz, zmienisz kolejność albo usuniesz.

✂️

Zaznaczaj i przesuwaj razem

Zaznacz ramką, dodawaj i zabieraj Shift+klikiem, a potem przesuń węzły, strefy, teksty i punkty połączeń jednym ruchem.

⌨️

Skróty klawiszowe

Kopiuj, wytnij, wklej, duplikuj, zaznacz wszystko, usuń, przesuwaj strzałkami, przybliżaj, dopasuj, zmień nazwę. Pełna lista pod F1.

📤

Eksport

Zapisz przenośny plik JSON ze wszystkimi ikonami albo wyeksportuj obraz PNG z wyborem rozdzielczości, tła i przycięcia.

🖼️

Własne ikony

Zaimportuj dowolny obraz (PNG, SVG, JPG) jako ikonę. Zapisuje się w diagramie, więc podróżuje razem z plikiem.

🌍

10 języków

Polski, angielski, niemiecki, francuski, hiszpański, włoski, portugalski, czeski, niderlandzki i ukraiński. Cały interfejs jest przetłumaczony, łącznie z nazwami ikon, a wybrany język jest zapamiętywany.

🤖

Asystenci AI (MCP)

Opisz system, a Claude albo inny asystent MCP narysuje go za Ciebie: ikony, strefy, połączenia i rozmieszczenie. Działa też z lokalnymi modelami.

🔐

Konta i udostępnianie

Na Twoim serwerze w Dockerze: logowanie, role administratora, edytora i czytelnika, prywatne diagramy udostępniane wybranym osobom oraz linki tylko do odczytu.

Z bliska

Pobierz aplikację na komputer

Własne okno, bez przeglądarki. Diagramy zapisują się jako pliki w folderze Dokumenty/ArchFlow.

🐧

Linux · AppImage

Działa na każdej dystrybucji. Nadaj prawo uruchamiania i odpal.

ArchFlow-X.Y.Z-x86_64.AppImage

📦

Debian / Ubuntu · .deb

Instaluje ArchFlow z pozycją w menu.

ArchFlow-X.Y.Z-amd64.deb

🪟

Windows · instalator

Wybierasz folder, dostajesz skróty na pulpicie i w menu Start.

ArchFlow-Setup-X.Y.Z.exe

⬇ Pobierz z ostatniego wydania

Windows: instalator nie jest jeszcze podpisany certyfikatem, więc SmartScreen może pokazać ostrzeżenie przy pierwszym uruchomieniu. Kliknij Więcej informacji → Uruchom mimo to.

Uruchom u siebie

Gotowy obraz jest publikowany w GitHub Container Registry. Nie musisz klonować repozytorium, wystarczy plik compose.

mkdir archflow && cd archflow
curl -O https://raw.githubusercontent.com/cyryllo/ArchFlow/master/compose.yml
docker compose pull
docker compose up -d

Potem otwórz http://localhost:9500. Wolisz zwykłe docker run?

docker run -d --name archflow \
  -p 9500:80 \
  -v "$(pwd)/diagrams:/data/diagrams" \
  --restart unless-stopped \
  ghcr.io/cyryllo/archflow:latest
  • Port 9500 domyślnie, żeby nie kolidować z usługami na 80 czy 8080.
  • Twoje dane zostają u Ciebie. Każdy diagram to zwykły plik JSON w ./diagrams. Kopia tego folderu wystarczy.
  • Startuje w kilka sekund, działa offline. Wszystko jest w obrazie.
  • Sam się podnosi po awarii albo restarcie maszyny.
  • Łatwa aktualizacja: docker compose pull && docker compose up -d. Diagramy zostają.
  • Konta i udostępnianie: logowanie z rolami, panel administratora, prywatne diagramy, linki tylko do odczytu i opcjonalny dostęp publiczny bez zapisu na serwer.
  • Asystenci AI łączą się z wbudowanym serwerem MCP pod /mcp osobistymi tokenami.

Logowanie. Powyższy compose.yml je włącza: zaraz po uruchomieniu otwórz ArchFlow i utwórz konto administratora. Przez internet wystaw go za HTTPS (np. Nginx Proxy Manager).

Niech asystent AI to narysuje

ArchFlow ma serwer MCP. Opisz system zwykłymi słowami, a Claude albo inny asystent obsługujący MCP zbuduje diagram: ikony, strefy, połączenia i rozmieszczenie. Zapisze go tam, gdzie ArchFlow trzyma diagramy, więc otworzysz go w Moich diagramach i dalej poprawisz ręcznie.

claude mcp add archflow --scope user \
  -e ARCHFLOW_URL=http://localhost:9500 \
  -- npx -y archflow-mcp@latest

Tak w Claude Code. Claude Desktop i inne programy wymagają kilku linijek konfiguracji.

  • Buduje i zmienia całe diagramy, odpowiada na pytania o nie i szuka ikon w każdym z 10 języków.
  • Działa z aplikacją desktopową, folderem z plikami albo ArchFlow w Dockerze, gdzie serwer jest wbudowany, a każdy używa własnego tokenu.
  • Także z lokalnymi modelami: przez programy takie jak Open WebUI, Continue czy LM Studio, np. z Qwen albo Gemmą z Ollamy.
  • Sprawdza przed zapisem według zasad samego ArchFlow, więc do diagramów nie trafia nic zepsutego.

Dwa sposoby na zapisanie pracy

Używaj jednego albo obu. Są od siebie niezależne.

💾 Pliki na Twoim komputerze

Wyeksportuj diagram jako plik .json (☰ → Eksportuj do JSON) i otwórz go później (☰ → Otwórz z pliku).

  • Dostępne wszędzie, także w tym demo
  • Zawiera wszystkie ikony, również zaimportowane
  • Świetne na kopie zapasowe i do wysyłania innym
  • Do tego: eksport obrazu PNG

🗄️ Moje diagramy

ArchFlow trzyma listę nazwanych diagramów: przyciski Zapisz i Moje diagramy na górnym pasku.

  • Docker: pliki w ./diagrams na serwerze, wspólne dla zespołu
  • Aplikacja desktopowa: pliki w Dokumenty/ArchFlow
  • Docker z logowaniem: prywatne diagramy, udostępnianie osobom, linki tylko do odczytu
  • Górny pasek pokazuje Zmodyfikowany, dopóki nie zapiszesz

Jako zwykła strona WWW (tak jak demo) ArchFlow może trzymać diagramy tylko w pamięci przeglądarki. Jest mała i znika po wyczyszczeniu danych przeglądarki, więc eksportuj pracę do pliku.
