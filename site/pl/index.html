Izometryczne diagramy architektury, bez kombinowania

ArchFlow to edytor czytelnych i ładnych diagramów izometrycznych systemów, sieci i infrastruktury chmurowej. Używaj go w przeglądarce, postaw u siebie jedną komendą Dockera albo uruchom jako aplikację desktopową.

▶ Wypróbuj demo 🐳 Uruchom w Dockerze ★ GitHub

Co możesz zrobić

Wszystko, czego potrzeba, żeby narysować architekturę, wytłumaczyć ją innym i utrzymywać ją aktualną.

🧊

Izometryczny obszar roboczy

Przeciągaj komponenty na izometryczną siatkę, przybliżaj, przesuwaj i dopasuj cały diagram do ekranu.

☁️

Duża biblioteka ikon

Wbudowane ikony Isoflow oraz paczki AWS, Azure, Google Cloud i Kubernetes, ładowane na żądanie, żeby start był szybki.

🖼️

Własne ikony

Zaimportuj dowolny obraz (PNG, SVG, JPG) jako ikonę. Zapisuje się w diagramie, więc podróżuje razem z plikiem.

🔗

Połączenia, strefy, etykiety

Łącz elementy kliknięciem albo przeciągnięciem, grupuj je w kolorowe strefy, dodawaj tekst i opisy z formatowaniem.

⚡

Szybka edycja

Cofnij/ponów, zaznaczanie prostokątem i lassem odręcznym oraz konfigurowalne skróty klawiszowe.

📤

Eksport

Zapisz diagram jako przenośny plik JSON albo wyeksportuj obraz PNG z wybraną rozdzielczością, tłem i przycięciem.

🗄️

Zapis na Twoim serwerze

W Dockerze diagramy są zapisywane jako pliki na serwerze, wspólne dla całego zespołu, z linkami tylko do odczytu.

🖥️

Aplikacja desktopowa

Aplikacja Electron dla Windows, macOS i Linuksa, która zapisuje diagramy prosto do katalogu Dokumenty.

🌍

Polski i angielski

Cały interfejs jest przetłumaczony, a wybrany język jest zapamiętywany.

Z bliska

Uruchom na swoim serwerze

Gotowy obraz jest opublikowany w GitHub Container Registry. Nie trzeba klonować repozytorium, wystarczy pobrać plik compose.

mkdir archflow && cd archflow
curl -O https://raw.githubusercontent.com/cyryllo/ArchFlow/master/compose.yml
docker compose pull
docker compose up -d

Potem otwórz http://localhost:9500. Wolisz zwykłe docker run?

docker run -d --name archflow \
  -p 9500:80 \
  -v "$(pwd)/diagrams:/data/diagrams" \
  --restart unless-stopped \
  ghcr.io/cyryllo/archflow:latest
  • Domyślnie port 9500, więc nie gryzie się z innymi usługami na 80 czy 8080.
  • Twoje dane są Twoje. Każdy diagram to zwykły plik JSON w ./diagrams. Kopia tego katalogu wystarczy za backup.
  • Startuje w kilka sekund, działa bez internetu. Wszystko jest w obrazie.
  • Sam wstaje po awarii albo restarcie maszyny.
  • Łatwa aktualizacja: docker compose pull && docker compose up -d. Diagramy zostają.

Brak logowania. Każdy, kto otworzy adres, może edytować diagramy w Dysku aplikacji. Trzymaj go w zaufanej sieci albo za reverse proxy z uwierzytelnianiem.

Używaj jednego albo obu. Działają niezależnie.

💾 Pliki na Twoim komputerze

Pobierz diagram jako plik .json i otwórz go ponownie później.

  • Dostępne wszędzie, także w tym demo
  • Plik zawiera wszystkie ikony, także zaimportowane
  • Idealne do kopii zapasowych i wysyłania diagramów innym
  • Do tego eksport diagramu jako obraz PNG

🌐 Dysk aplikacji

ArchFlow sam przechowuje listę nazwanych diagramów.

  • Docker: pliki w ./diagrams na serwerze, wspólne dla zespołu
  • Aplikacja desktopowa: pliki w Dokumenty/ArchFlow
  • Linki tylko do odczytu (Docker)
  • Zapis jest ręczny, znacznik „Zmodyfikowany” pokazuje niezapisane zmiany

Hostowany jako zwykła strona (tak jak demo) ArchFlow może trzymać diagramy tylko w pamięci przeglądarki. Jest ona mała i znika po wyczyszczeniu danych przeglądarki, więc używaj Eksportuj Plik, żeby nie stracić pracy.
