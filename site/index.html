Isometric diagrams of systems and processes, without the hassle

ArchFlow is an editor for clear, good-looking isometric diagrams: system architecture, networks, cloud infrastructure and business processes. Use it in the browser, install it on Linux or Windows, or host it yourself with one Docker command.

▶ Try the demo ⬇ Download 🚀 Quick start 🐳 Run with Docker

What you can do

Everything you need to sketch an architecture or a process, explain it to others and keep it up to date.

🧊

Isometric canvas

Place components on an isometric grid, group them in coloured zones, connect them and add text. Zoom, pan and fit the whole diagram to the screen.

🎨

177 icons in 9 categories

One consistent icon set, colour-coded by category: servers & computers, network, communication, data, security, people, flow & process, business & logistics, shapes.

🔀

Not only infrastructure

Draw business and order processes too: start and end events, decisions, gateways, documents, approvals, timers and milestones.

🖱️

Right-click everything

Add nodes, zones and text on the empty canvas; connect, copy, duplicate, reorder or delete elements from their own menu.

✂️

Select and move together

Drag a selection box, Shift+click to add or remove, then move nodes, zones, text and connector points in one go.

⌨️

Keyboard shortcuts

Copy, cut, paste, duplicate, select all, delete, nudge with the arrow keys, zoom, fit, rename. Press F1 for the full list.

📤

Export anywhere

Save a portable JSON file with every icon included, or export a PNG with your choice of resolution, background and cropping.

🖼️

Your own icons

Import any image (PNG, SVG, JPG) as an icon. It's saved inside the diagram, so it travels with the file.

🌍

English & Polish

The whole interface is translated, icon names included, and your language is remembered.

Run it on your server

A ready-made image is published on GitHub Container Registry. You don't need to clone the repository, just download the compose file.

mkdir archflow && cd archflow
curl -O https://raw.githubusercontent.com/cyryllo/ArchFlow/master/compose.yml
docker compose pull
docker compose up -d

Then open http://localhost:9500. Prefer plain docker run?

docker run -d --name archflow \
  -p 9500:80 \
  -v "$(pwd)/diagrams:/data/diagrams" \
  --restart unless-stopped \
  ghcr.io/cyryllo/archflow:latest
  • Port 9500 by default, so it doesn't clash with other services on 80 or 8080.
  • Your data stays yours. Every diagram is a plain JSON file in ./diagrams. Back up that folder and you're done.
  • Starts in seconds, works offline. Everything is inside the image.
  • Restarts on its own after a crash or a reboot.
  • Easy updates: docker compose pull && docker compose up -d. Diagrams are kept.

No logins. Anyone who can open the address can edit diagrams in My diagrams. Keep it on a trusted network or behind a reverse proxy with authentication.

Two ways to keep your work

Use one or both. They're independent.

💾 Files on your computer

Export the diagram as a .json file (☰ → Export as JSON) and open it again later (☰ → Open from file).

  • Available everywhere, including this demo
  • Includes every icon, also your imported ones
  • Great for backups and sending diagrams to others
  • Also: export a PNG picture of the diagram

🗄️ My diagrams

ArchFlow keeps a list of named diagrams for you: Save and My diagrams in the top bar.

  • Docker: files in ./diagrams on your server, shared by the team
  • Desktop app: files in Documents/ArchFlow
  • Read-only share links (Docker)
  • The top bar shows Modified until you save

Hosted as a plain website (like the demo), ArchFlow can only keep diagrams in your browser's storage. That's small and disappears when you clear browser data, so export your work to a file.
